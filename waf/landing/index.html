300B 실습 환경 — 4-tier (AWS-style)

이 페이지는 300b-waf (Apache + ModSecurity) 의 landing vhost 가 응답한 것입니다. 모든 트래픽이 fw → waf 를 통과하며 ModSecurity 검사를 받습니다. 직접 :3000, :8080 등 backend 포트는 외부 노출되지 않습니다.

취약 웹 (학생 PC /etc/hosts 또는 DNS 설정 후 접속)

Juice Shop juice.300b DVWA dvwa.300b NeoBank neobank.300b GovPortal govportal.300b MediForum mediforum.300b AdminConsole admin.300b AICompanion ai.300b

운영 콘솔

Wazuh Dashboard wazuh.300b (admin / SecretPassword) Bastion API bastion.300b/health

SSH (Bastion 점프 모델)

모든 내부 컨테이너 SSH 는 bastion (port 2204) 만 외부 노출되어 있습니다. 다른 컨테이너 (waf, secu, siem, attacker, fw, ids) 는 ProxyJump 로만 접근 가능합니다.

학생 PC ~/.ssh/config 에 한 번 추가:

Host 300b-bastion
  HostName <VM_IP>
  Port 2204
  User ccc

Host 300b-*
  ProxyJump 300b-bastion
  User ccc

그러면 다음과 같이 접속:

ssh 300b-bastion              # 직접 (점프 호스트)
ssh 300b-attacker             # bastion 경유 자동
ssh 300b-waf                  # bastion 경유 자동
ssh 300b-fw                   # bastion 경유 자동
ssh 300b-ids                  # bastion 경유 자동

기본 SSH 암호 = ccc (.env 의 SSH_PASS). Bastion API 키 = 300b-api-key-2026 (.env 의 API_KEY).
